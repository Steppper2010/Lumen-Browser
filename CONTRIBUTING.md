# Contributing to Lumen

Thanks for helping improve Lumen Browser.

1. Fork the repository and create a focused branch from `main`.
2. Install dependencies with `pnpm install --frozen-lockfile`.
3. Make the smallest clear change and run `pnpm check`.
4. Open a pull request describing the problem, solution, and manual testing.

Please keep unrelated changes in separate pull requests. UI changes should include screenshots. By contributing, you agree that your contribution is licensed under the MIT License.
