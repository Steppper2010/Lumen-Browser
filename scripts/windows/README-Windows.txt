Lumen Browser for Windows

Install:
1. Extract this ZIP archive.
2. Run Install-Lumen.bat.
3. Lumen will be copied to:
   %LOCALAPPDATA%\Programs\Lumen
4. Desktop and Start Menu shortcuts will be created.

Portable launch:
You can also open Lumen\Lumen.exe directly without installing.

Note:
This build is not code-signed yet. Windows SmartScreen may show a warning on first launch.
